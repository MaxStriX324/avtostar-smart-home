# Производственные файлы

AVTOSTAR ESP-12F Debug Module, 50 × 35 мм, два медных слоя, толщина 1,6 мм.

[Архив Gerber и Excellon](AVTOSTAR_ESP12F_50x35_Gerber.zip) содержит девять Gerber-слоёв, файл задания .gbrjob и единый файл сверловки .drl.

Контур платы — 50 × 35 мм. Сверловка: 42 переходных отверстия и 12 отверстий J2, Ø0,8 мм, металлизированные. Начало координат Gerber и Excellon совпадает с верхним левым углом платы.

Архив содержит один комплект сверловки. Использовать его целиком, без добавления файлов сверловки из других экспортов.

Перед передачей в производство выполнить ERC/DRC в KiCad и проверку заказа в CAM производителя.

# Hardware

Three product-specific PCB projects are planned; **no released KiCad schematic or verified PCB yet**.

- `switch-2/` — capacitive 2-key endpoint, W/WC assembly options.
- `relay-2/` — 2-output endpoint, W/WC assembly options.
- `control/` — gateway board based on ESP32-S3.
- `common/` — power, CAN and RF review checklist templates.

Each endpoint should have one PCB layout/revision and two BOM population sets: `W` and `WC`.

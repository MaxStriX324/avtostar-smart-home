# Общие аппаратные узлы

В качестве аппаратной основы для отладки используется [ESP-12F Debug Module v1.0](../esp12f-debug-module/).

- Питание ESP-12F и MAX3485 — 3,3 В.
- EN и RST: подтяжка к питанию, RC-цепь EN; загрузочные уровни GPIO0/2/15.
- UART0 и RS-485: управление DE и /RE, подтяжка направления к GND, разъединение RO и RXD при прошивке.
- Дифференциальные линии A/B: защита SM712, сигнальная земля, оконечное согласование и смещение по параметрам сети.
- Зона антенны: отсутствие меди под антенной на всех слоях.
- Для выходных устройств: аппаратно определённое безопасное состояние при сбросе и работе загрузчика.

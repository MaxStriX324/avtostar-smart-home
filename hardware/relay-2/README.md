# AVTOSTAR Relay 2

Двухканальный модуль управления нагрузками на ESP-12F.

## Функции

- Два независимо управляемых выхода.
- Приём команд Switch 2 и Control, хранение привязок, передача состояния.
- Вариант W: Wi-Fi и ESP-NOW.
- Вариант WR: Wi-Fi, ESP-NOW и RS-485 на MAX3485.

Выходные каскады должны иметь аппаратное безопасное состояние при включении и сбросе микроконтроллера. Для нагрузок 12/24 В DC и 230 В AC определяются отдельные электрические характеристики, коммутационные элементы, защита и требования к изоляции.

Для аппаратной и программной отладки применяется [ESP-12F Debug Module](../esp12f-debug-module/). Назначение выводов специализированной платы определяется при разработке её схемы.

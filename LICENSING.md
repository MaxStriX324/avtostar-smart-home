# Licensing plan (pending decision)

Repository contents are currently an early-stage engineering draft. There is **no blanket open-source license grant yet**. The author must approve the final license before external reuse or hardware manufacturing is authorized.

Proposed separation to review before public release:

- Firmware and software: a dedicated software license (for example Apache-2.0 or MIT).
- Schematics, PCB layouts and mechanical drawings: a hardware-oriented license (for example CERN-OHL-S/P/W).
- Documentation: a separately chosen documentation license if needed.
- AVTOSTAR name and visual mark: trademark and branding rules, separate from source licensing.
- Vendor libraries, SDKs, radio stacks and KiCad symbols: retain all third-party notices.

Publishing source code publicly **does not automatically authorize commercial manufacturing** of a future branded product; any intended rights must be defined explicitly in the selected licenses and trademark policy.
